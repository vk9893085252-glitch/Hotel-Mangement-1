# HOTEL MANAGEMENT SYSTEM

## Project Description

The **Hotel Management System** is a C++-based console application developed to simplify and organize the daily operations of a hotel. The main purpose of this project is to provide an efficient way to manage hotel rooms, customer registrations, room bookings, food orders, billing, staff attendance, and salary payments through a single application.

The system provides separate login facilities for customers and administrators, allowing them to access features according to their roles. Customers can register, log in, view room availability, book rooms, order food, and calculate their bills during checkout. Administrators can manage room details, add food items, update prices, monitor bookings, view revenue reports, manage staff records, track attendance, calculate salaries, and record salary payments.

This project is developed using **C++ and Object-Oriented Programming (OOP)** concepts, including classes, objects, encapsulation, inheritance, abstraction, and polymorphism. It also demonstrates additional programming concepts such as function overloading, operator overloading, templates, vectors, structures, and exception handling.

To maintain records between program executions, the system uses file handling to store and retrieve information from text files. This helps preserve important records such as rooms, customers, bookings, food items, staff, attendance, and salary payments.

The Hotel Management System is designed as an educational project to demonstrate how programming concepts can be applied to a practical, real-world management problem. It helps organize hotel operations, reduces manual calculations, and provides a foundation for future improvements, such as database integration, a graphical user interface, enhanced security, and online booking facilities.

**In conclusion, this project demonstrates the practical application of C++ programming in developing a structured hotel management application that combines multiple hotel operations in one system.**
